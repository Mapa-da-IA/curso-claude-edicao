Aula 03: Instalando Skills pelo Claude Desktop

Primeiros passos

Duração de referência
≈ 7–10 min (estimativa editorial do guia)
Nível
Iniciante · Claude Cowork

Objetivos da aula

  1. Explicar o que é uma Skill com a comparação do manual especializado que o Claude consulta durante o trabalho.
  2. Diferenciar os papéis do Claude, do Remotion e das Skills.
  3. Mostrar como localizar Skills e Plugins no diretório do Claude Desktop e verificar origem, compatibilidade e permissões antes de instalar.
  4. Pedir ao Cowork que use as orientações oficiais do Remotion para melhorar a animação de cinco segundos, preservando a versão original.

Contexto narrativo

Tema: como adicionar conhecimentos especializados ao Claude. Na aula anterior, o aluno preparou o ambiente de criação e produziu a primeira animação de cinco segundos. Agora ele vai entender o que são Skills, localizar recursos confiáveis pela interface visual do Claude Desktop e pedir ao Cowork que use as orientações oficiais do Remotion para melhorar essa animação.

Dica

DIDÁTICA DA AULA: a tela principal é a conversa no Claude Desktop, não o terminal. Mostre três momentos: o pedido enviado ao Claude, a execução do trabalho e a comparação visual do resultado. Vale a regra principal do curso: Sempre que uma tarefa precisar de instalação, configuração ou acesso ao computador, peça ao Claude que verifique as ferramentas disponíveis, execute o que for possível com as permissões concedidas e explique apenas as etapas que realmente exigirem intervenção do aluno.

Roteiro de cenas e condução

  1. Resultado anterior: Mostre a animação de cinco segundos criada na aula 2.
  2. Conceito: Apresente a comparação do editor de vídeos que recebe um manual especializado e a divisão entre Claude, Remotion e Skills.
  3. Pré-requisito: Mostre onde fica a opção Code execution and file creation, necessária para usar Skills.
  4. Diretório: Abra Customize (Personalizar) > Discover e pesquise por Remotion.
  5. Verificação: Confira com a turma a origem, a compatibilidade com o Cowork e as permissões antes de adicionar qualquer recurso.
  6. Pedido ao Cowork: Envie o prompt de configuração e acompanhe a execução.
  7. Comparação: Mostre a animação original e a nova versão lado a lado. Explique que a Skill orienta a execução, mas não garante resultados perfeitos.
  8. Gancho: Na próxima aula, vamos criar nossa própria Skill com o padrão visual do curso.

1. Começando pelo conceito

Apresente a seguinte comparação: imagine que você contratou um editor de vídeos. Ele já sabe trabalhar com várias ferramentas, mas você quer que ele siga determinadas técnicas de animação e organização. Uma Skill funciona como um manual especializado que o Claude pode consultar durante o trabalho.

Quem faz o quê
PeçaPapel
ClaudeRealiza as tarefas.
RemotionPermite construir os vídeos.
SkillsFornecem orientações especializadas.

Uma Skill não substitui o programa de edição.

2. Antes de instalar: ative a execução de código

As Skills só funcionam com o recurso Code execution and file creation (Execução de código e criação de arquivos) ativado. Mostre onde ele fica antes de abrir o diretório:

  • Planos Free, Pro e Max: abra Settings (Configurações) > Capabilities (Capacidades) e ative Code execution and file creation (Execução de código e criação de arquivos).
  • Planos Team e Enterprise: quem administra a conta (owner) ativa o recurso em Organization settings (Configurações da organização) > Plugins & skills.

Atenção

Os nomes dos menus aparecem aqui em inglês, como na interface oficial, com a tradução entre parênteses. Se o seu aplicativo estiver em português, os rótulos podem ser um pouco diferentes. Confira os rótulos no aplicativo antes de gravar.

3. Instalando pelo aplicativo

  1. Passo 1: abra o Claude Desktop e selecione Customize (Personalizar).
  2. Passo 2: abra Discover (Descobrir), o diretório que reúne Skills, conectores e plugins, e pesquise por Remotion. O mesmo diretório também abre por Customize > Skills > "+" > Browse skills (Explorar skills).
  3. Passo 3: confira a origem, a compatibilidade com Cowork e as permissões antes de adicionar o recurso.

O diretório oficial permite instalar Skills e Plugins pela interface e está disponível nos planos Pro, Max, Team e Enterprise. O Remotion mantém um plugin oficial para Claude Code (publicado como remotion-dev/claude-code-plugin), instalado no Claude Desktop pela aba Code, em Customize > Plugins > Discover, pesquisando "remotion".

Atenção

O funcionamento do plugin do Remotion no Cowork não está documentado. Se o plugin não oferecer a função de criação de vídeos no Cowork, utilizaremos a documentação oficial do Remotion como referência e pediremos ao Claude para configurar o projeto com as ferramentas disponíveis. Teste no seu ambiente antes de gravar.

4. Pedindo a configuração pelo Cowork

Envie o pedido abaixo no Cowork. Ele cobre os dois caminhos: usar um recurso compatível, se existir, ou seguir a documentação oficial do Remotion.

Mostre a diferença entre a animação original e a nova versão. Explique que a Skill ajuda a orientar a execução, mas não garante resultados perfeitos.

Dica

AGORA É A VEZ DO ALUNO: ele ativa a execução de código, procura o Remotion no diretório, envia o mesmo prompt no próprio Cowork e compara a animação original com a nova versão, anotando pelo menos duas diferenças (por exemplo, tipografia ou suavidade do movimento).

Resultado esperado: o aluno saberá localizar Skills e Plugins confiáveis, verificar a instalação e solicitar o uso dessas orientações em uma tarefa real.

Dica

Skills orientam o trabalho do Claude, mas não substituem o nosso olhar como editor. A avaliação final da animação continua sendo nossa.

Checklist do professor

  • Mostrou a animação de cinco segundos da aula anterior antes de falar de Skills
  • Explicou a diferença entre Claude, Remotion e Skills com a comparação do manual especializado
  • Mostrou onde ativar Code execution and file creation
  • Abriu Customize > Discover, pesquisou por Remotion e conferiu origem, compatibilidade com Cowork e permissões
  • Enviou o prompt de demonstração no Cowork e preservou a versão original
  • Comparou as duas versões e explicou que a Skill não garante resultados perfeitos

AULA 03 / NARRAÇÃO

Texto contínuo para locução

Na última aula, preparamos nosso ambiente de criação e produzimos nossa primeira animação.

Agora vamos conhecer um recurso que pode ajudar o Claude a trabalhar de maneira mais especializada.

Esse recurso se chama Skill.

Mas o que é uma Skill?

Imagine que você está trabalhando com um editor de vídeos e quer ensinar a ele algumas técnicas específicas.

Você poderia entregar um manual explicando como organizar cenas, trabalhar com textos e criar animações.

Uma Skill funciona de maneira parecida.

Ela reúne instruções que o Claude pode consultar quando estiver realizando uma determinada tarefa.

E o mais interessante é que não precisamos criar todas essas orientações.

Existem Skills e Plugins disponibilizados por desenvolvedores e empresas.

Vamos abrir o Claude Desktop e acessar a área Personalizar.

Aqui podemos encontrar recursos que ajudam a ampliar as possibilidades do Claude.

Como estamos aprendendo a criar vídeos, vamos procurar por Remotion.

É importante conferir quem desenvolveu cada recurso e se ele funciona no ambiente que estamos utilizando.

Não devemos instalar qualquer ferramenta simplesmente porque ela promete resultados interessantes.

Agora vamos pedir ao Claude que verifique as orientações oficiais do Remotion e identifique a opção compatível com nosso projeto.

Depois disso, vamos realizar um teste prático.

Quero melhorar a animação de cinco segundos criada na aula anterior.

Vamos solicitar uma tipografia mais organizada e uma entrada de texto mais suave.

Também vamos pedir para preservar a primeira versão, porque queremos comparar os dois resultados.

Agora observe a diferença.

O objetivo das Skills não é substituir nosso olhar como editor.

Elas fornecem orientações que podem ajudar o Claude a realizar tarefas com mais consistência.

Na próxima aula, vamos aprender a criar nossa própria Skill, para ensinar ao Claude um padrão visual que utilizaremos durante todo o curso.

Dica

USO DA LOCUÇÃO: Este é um texto-base de narração para leitura e adaptação pelo professor. Ajuste as frases à demonstração realmente gravada. A área Personalizar pode aparecer como Customize no aplicativo; confira também, antes de gravar, se o plugin do Remotion aparece no diretório e se funciona no Cowork.
