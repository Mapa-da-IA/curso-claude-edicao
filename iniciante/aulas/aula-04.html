Aula 04: Criando sua primeira Skill personalizada

Primeiros passos

Duração de referência
≈ 7–10 min (estimativa editorial do guia)
Nível
Iniciante · Claude Cowork

Objetivos da aula

  1. Mostrar por que repetir resolução, formato, fontes, cores, margens e estilo de animação em cada pedido não é prático.
  2. Definir o padrão de edição do curso e a regra de preservar os arquivos originais.
  3. Pedir ao Claude que crie a Skill direcao-de-edicao e prepare o ZIP, sem edição manual de código.
  4. Adicionar a Skill pela interface do Claude Desktop e testá-la na animação de cinco segundos.

Contexto narrativo

Tema: como ensinar ao Claude seu próprio estilo de edição. Na aula anterior, o aluno usou orientações prontas do Remotion. Agora ele vai criar uma Skill chamada direcao-de-edicao, para que o Claude siga regras visuais consistentes nos próximos projetos. O próprio Claude prepara os arquivos e o ZIP; o aluno só descreve as regras e adiciona o pacote pela interface.

Dica

DIDÁTICA DA AULA: a tela principal é a conversa no Claude Desktop. Mostre o pedido, a execução e a comparação do resultado. Vale a regra principal do curso: Sempre que uma tarefa precisar de instalação, configuração ou acesso ao computador, peça ao Claude que verifique as ferramentas disponíveis, execute o que for possível com as permissões concedidas e explique apenas as etapas que realmente exigirem intervenção do aluno.

Roteiro de cenas e condução

  1. O problema: Mostre que, a cada vídeo, seria preciso repetir resolução, formato, fontes, cores, margens e estilo de animação.
  2. Padrão do curso: Apresente a tabela com o padrão de edição e a regra de preservar os arquivos originais.
  3. Criação pela conversa: Envie o prompt de criação da Skill e acompanhe o Claude preparando os arquivos e o ZIP.
  4. Conferência: Mostre a estrutura do ZIP (pasta direcao-de-edicao com o arquivo SKILL.md).
  5. Upload: Em Customize (Personalizar) > Skills, adicione o ZIP e confirme que a Skill aparece ativada.
  6. Teste: Envie o prompt de teste e compare a nova versão com a anterior.
  7. Gancho: Na próxima aula, vamos usar essas orientações para criar o primeiro vídeo completo de trinta segundos.

1. O problema que vamos resolver

Explique que, sempre que criamos um vídeo, precisamos informar resolução, formato, fontes, cores, margens e estilo de animação.

Repetir tudo isso em cada pedido não é prático. Vamos criar uma Skill que armazene essas orientações e possa ser reutilizada.

2. Definindo nosso estilo visual

Padrão de edição do curso
ItemValor
Formato vertical1080 × 1920
Quadros por segundo30 FPS
Margens mínimas80 px
Fonte principalMontserrat
Cores da identidadePreto, branco e laranja
Estilo de animaçãoMovimentos suaves

Vamos também estabelecer uma regra fundamental: preservar os arquivos originais e modificar apenas o que foi solicitado.

3. Criando a Skill pela conversa

Envie o pedido abaixo. O Claude prepara todos os arquivos e o ZIP, sem que o aluno precise escrever código.

Dica

O Claude prepara o pacote para você. Para conferir se ele está correto: o arquivo direcao-de-edicao.zip deve conter uma pasta direcao-de-edicao e, dentro dela, o arquivo SKILL.md. No início do SKILL.md ficam dois campos: name (o nome da Skill, só com letras minúsculas, números e hífens, até 64 caracteres e igual ao nome da pasta) e description (o que a Skill faz e quando deve ser usada). O nome direcao-de-edicao segue essas regras.

Atenção

A Skill só funciona com Code execution and file creation (Execução de código e criação de arquivos) ativado, como vimos na aula 3. Confira antes de gravar.

4. Ativando a Skill

Após receber o ZIP, adicione a Skill pela interface:

  1. No Claude Desktop, abra Customize (Personalizar) > Skills.
  2. Clique em "+" e escolha "+ Create skill" (Criar skill).
  3. Selecione Upload a skill (Fazer upload de uma skill).
  4. Escolha o arquivo ZIP preparado pelo Claude.
  5. Confira se a Skill direcao-de-edicao aparece na lista de Skills e se está ativada.

Esse é o procedimento previsto para Skills personalizadas associadas à conta Claude.

Atenção

Os nomes dos menus aparecem aqui em inglês, como na interface oficial, com a tradução entre parênteses. Se o seu aplicativo estiver em português, os rótulos podem ser um pouco diferentes. Confira os rótulos no aplicativo antes de gravar.

5. Testando a Skill

Agora faça um teste:

Mostre a versão anterior e a nova lado a lado. Destaque que não foi preciso repetir os detalhes do padrão visual no pedido.

Dica

AGORA É A VEZ DO ALUNO: ele envia o prompt de criação no próprio Cowork, adiciona o ZIP em Customize > Skills, envia o prompt de teste e confere se a nova versão respeita margens, tipografia, cores e animação, sem apagar a anterior.

Resultado esperado: o aluno cria a Skill direcao-de-edicao pela conversa, adiciona o ZIP à conta pela interface e vê o Claude aplicar o padrão do curso em uma nova versão da animação, com a anterior preservada.

Dica

Se no futuro quisermos mudar alguma regra, basta pedir ao Claude uma versão atualizada da Skill e adicioná-la de novo.

Checklist do professor

  • Explicou por que repetir as mesmas especificações em cada pedido não é prático
  • Apresentou o padrão de edição do curso e a regra de preservar os arquivos originais
  • Enviou o prompt de criação e mostrou o ZIP com a pasta direcao-de-edicao e o arquivo SKILL.md
  • Adicionou o ZIP em Customize > Skills > "+" > Create skill > Upload a skill e confirmou a Skill ativada
  • Enviou o prompt de teste e comparou a nova versão com a anterior, que continua preservada

AULA 04 / NARRAÇÃO

Texto contínuo para locução

Na aula anterior, aprendemos a utilizar Skills para ajudar o Claude a realizar tarefas específicas.

Mas existe algo ainda mais interessante.

Nós também podemos criar nossas próprias Skills.

E isso é muito útil quando queremos manter um padrão visual em vários projetos.

Imagine que você precise informar todas as vezes que seu vídeo será vertical, que os textos precisam respeitar margens e que as animações devem ser suaves.

Isso acaba se tornando repetitivo.

Por isso, vamos criar uma Skill que reúna essas regras.

Ela terá o nome de direção de edição.

Nossa Skill vai orientar o Claude sobre como organizar os elementos visuais dos nossos vídeos.

Vamos definir uma resolução vertical, trinta quadros por segundo e margens de segurança.

Também vamos escolher nossa fonte principal e as cores que utilizaremos.

Mas não precisamos escrever os arquivos manualmente.

Vamos pedir ao próprio Claude para criar a Skill.

Basta explicar quais regras queremos guardar.

O Claude poderá organizar essas informações em um arquivo específico e preparar um pacote para instalação.

Depois disso, vamos acessar a área de Skills do Claude Desktop e adicionar o arquivo preparado.

Agora nossa Skill estará disponível na conta, desde que tenha sido instalada e ativada corretamente.

Vamos fazer um teste utilizando a animação que já criamos.

Quero que o Claude aplique as regras de direção de edição e produza uma nova versão para comparação.

Depois, vamos conferir o resultado.

Perceba que não precisamos explicar novamente todos os detalhes do nosso padrão visual.

A Skill ajuda a reutilizar essas orientações.

E, se no futuro quisermos mudar alguma regra, também poderemos pedir ao Claude para preparar uma versão atualizada.

Assim, nossas instruções podem evoluir com nossos projetos.

Na próxima aula, vamos utilizar essas orientações para criar nosso primeiro vídeo completo de trinta segundos.

Dica

USO DA LOCUÇÃO: Este é um texto-base de narração para leitura e adaptação pelo professor. Ajuste as frases à demonstração realmente gravada. Na tela, o nome técnico da Skill aparece como direcao-de-edicao (sem acentos e com hífens).
