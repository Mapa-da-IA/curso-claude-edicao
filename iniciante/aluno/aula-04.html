Aula 04: Criando sua primeira Skill personalizada

Primeiros passos

Duração
≈ 7–10 min
Nível
Iniciante · Claude Cowork

Objetivos da aula

  1. Ao final desta aula, você vai ter uma Skill chamada direcao-de-edicao com o padrão visual do curso.
  2. Você vai pedir ao Claude que prepare os arquivos e o ZIP da Skill, sem editar código.
  3. Você vai adicionar a Skill à sua conta pela interface do Claude Desktop e testá-la na animação de cinco segundos.

Nesta aula, você vai criar a Skill direcao-de-edicao, que guarda o padrão visual do curso. Assim, o Claude passa a seguir as mesmas regras em todos os vídeos, sem que você precise repeti-las em cada pedido.

Antes de começar

  • Code execution and file creation (Execução de código e criação de arquivos) ativado, como na aula 3.
  • A animação de cinco segundos criada na aula 2.

1. Por que criar uma Skill

Sempre que criamos um vídeo, precisamos informar resolução, formato, fontes, cores, margens e estilo de animação. Repetir tudo isso em cada pedido não é prático. Uma Skill armazena essas orientações e pode ser reutilizada.

2. O padrão de edição do curso

Padrão de edição do curso
ItemValor
Formato vertical1080 × 1920
Quadros por segundo30 FPS
Margens mínimas80 px
Fonte principalMontserrat
Cores da identidadePreto, branco e laranja
Estilo de animaçãoMovimentos suaves

Regra fundamental: preservar os arquivos originais e modificar apenas o que foi solicitado.

3. Peça ao Claude para criar a Skill

Envie este pedido no Cowork:

Dica

O Claude prepara o pacote para você. Para conferir se ele está correto: o arquivo direcao-de-edicao.zip deve conter uma pasta direcao-de-edicao e, dentro dela, o arquivo SKILL.md. No início do SKILL.md ficam dois campos: name (o nome da Skill, só com letras minúsculas, números e hífens, até 64 caracteres e igual ao nome da pasta) e description (o que a Skill faz e quando deve ser usada). O nome direcao-de-edicao segue essas regras.

4. Adicione a Skill à sua conta

  1. No Claude Desktop, abra Customize (Personalizar) > Skills.
  2. Clique em "+" e escolha "+ Create skill" (Criar skill).
  3. Selecione Upload a skill (Fazer upload de uma skill).
  4. Escolha o arquivo ZIP preparado pelo Claude.
  5. Confira se a Skill direcao-de-edicao aparece na lista de Skills e se está ativada.

Atenção

Os nomes dos menus aparecem aqui em inglês, como na interface oficial, com a tradução entre parênteses. Se o seu aplicativo estiver em português, os rótulos podem ser um pouco diferentes.

5. Teste a Skill

Agora faça um teste:

Compare a nova versão com a anterior e confira margens, tipografia, cores e animação.

Resultado esperado

A Skill direcao-de-edicao está ativada na sua conta e o Claude aplicou o padrão do curso em uma nova versão da animação, sem apagar a anterior. Você não precisou repetir os detalhes do padrão visual no pedido.

Dica

Se quiser mudar alguma regra no futuro, peça ao Claude uma versão atualizada da Skill e adicione o novo ZIP.

Checklist da aula

  • Enviei o prompt de criação e recebi o ZIP com a pasta direcao-de-edicao e o arquivo SKILL.md
  • Adicionei o ZIP em Customize (Personalizar) > Skills e a Skill aparece ativada
  • Enviei o prompt de teste e recebi uma prévia da nova versão
  • A versão anterior continua preservada para comparação
