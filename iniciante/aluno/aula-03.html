Aula 03: Instalando Skills pelo Claude Desktop

Nesta aula, você vai conhecer as Skills, procurar o Remotion no diretório do Claude Desktop e pedir ao Cowork uma versão melhorada da sua animação de cinco segundos, sem apagar a original.

Antes de começar

  • O Claude Desktop instalado, com uma conta em plano pago (o Cowork está disponível nos planos pagos).
  • A animação de cinco segundos criada na aula 2.

1. O que é uma Skill

Imagine que você contratou um editor de vídeos. Ele já sabe trabalhar com várias ferramentas, mas você quer que ele siga determinadas técnicas de animação e organização. Uma Skill funciona como um manual especializado que o Claude pode consultar durante o trabalho.

Quem faz o quê
PeçaPapel
ClaudeRealiza as tarefas.
RemotionPermite construir os vídeos.
SkillsFornecem orientações especializadas.

Uma Skill não substitui o programa de edição.

2. Ative a execução de código

As Skills só funcionam com o recurso Code execution and file creation (Execução de código e criação de arquivos) ativado:

  • Planos Free, Pro e Max: abra Settings (Configurações) > Capabilities (Capacidades) e ative Code execution and file creation (Execução de código e criação de arquivos).
  • Planos Team e Enterprise: quem administra a conta (owner) ativa o recurso em Organization settings (Configurações da organização) > Plugins & skills.

Atenção

Os nomes dos menus aparecem aqui em inglês, como na interface oficial, com a tradução entre parênteses. Se o seu aplicativo estiver em português, os rótulos podem ser um pouco diferentes.

3. Procure o Remotion no diretório

  1. Abra o Claude Desktop e selecione Customize (Personalizar).
  2. Abra Discover (Descobrir), o diretório que reúne Skills, conectores e plugins, e pesquise por Remotion. O mesmo diretório também abre por Customize > Skills > "+" > Browse skills (Explorar skills).
  3. Confira a origem, a compatibilidade com Cowork e as permissões antes de adicionar o recurso.

O diretório está disponível nos planos Pro, Max, Team e Enterprise. O Remotion mantém um plugin oficial para Claude Code (publicado como remotion-dev/claude-code-plugin), que aparece na aba Code, em Customize > Plugins > Discover, ao pesquisar "remotion".

Atenção

Não instale uma ferramenta só porque ela promete bons resultados: confira quem a publicou. O funcionamento do plugin do Remotion no Cowork não está documentado. Se ele não for compatível, o Claude usará a documentação oficial do Remotion como referência, como pede o prompt abaixo.

5. Compare as versões

Abra a animação original e a nova versão e anote pelo menos duas diferenças (por exemplo, tipografia ou suavidade do movimento).

Resultado esperado

Você sabe localizar Skills e Plugins confiáveis, verificar a instalação e pedir o uso dessas orientações em uma tarefa real: a animação original e a versão melhorada estão prontas para comparação.

Dica

Skills orientam o trabalho do Claude, mas não garantem resultados perfeitos nem substituem o seu olhar como editor. A avaliação final continua sendo sua.

Checklist da aula

  • Ativei Code execution and file creation (ou confirmei que já estava ativado)
  • Pesquisei por Remotion no diretório e conferi origem, compatibilidade com Cowork e permissões
  • Enviei o prompt no Cowork e a versão original foi preservada
  • Comparei as duas versões e anotei pelo menos duas diferenças
