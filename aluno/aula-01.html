Nesta aula, você vai conhecer o Claude, ver onde ele pode ser usado, comparar o Claude no navegador com o Claude Desktop e instalar o aplicativo no seu computador. Ainda não há prompts nem edição: a parte prática começa na próxima aula.

Antes de começar

  • Uma conta Claude. O plano Free já permite usar o aplicativo.
  • Um computador com Windows 10 ou posterior, ou um Mac (recomenda-se o macOS 14 ou posterior).

1. O que é o Claude

O Claude é o assistente de inteligência artificial da Anthropic. Com ele, você pode conversar, escrever, analisar documentos e, quando há ferramentas conectadas, executar tarefas nelas.

2. Onde usar o Claude

  • Navegador: pelo site claude.ai, sem instalar nada.
  • Computador: pelo aplicativo Claude Desktop, para Windows e macOS.
  • Celular: pelos aplicativos para dispositivos móveis.

Os planos são Free, Pro, Max, Team e Enterprise. O Free já inclui o aplicativo para computador, projetos e memória. O Max oferece mais uso que o Pro. Team e Enterprise são planos para empresas, com administração centralizada. Alguns recursos dependem do plano: o Claude Code e o Cowork estão nos planos pagos, e o uso do computador fica restrito ao Pro e ao Max.

Atenção

Recursos e planos mudam com frequência e variam de conta para conta. Confira o que a sua conta oferece em https://claude.com/pricing e na central de ajuda em https://support.claude.com.

O que só o Desktop tem

  • Aba Code: o Claude Code dentro do aplicativo, com sessões em paralelo, terminal, editor e revisão das alterações (diff).
  • Cowork: disponível no macOS e no Windows desde 9 de abril de 2026.
  • Uso do computador: só nos planos Pro e Max, em prévia de pesquisa. Precisa ser ativado em Configurações e exige o computador ligado e o aplicativo aberto.
  • Extensões locais (MCP): instaladas em Configurações > Extensões.
  • Entrada rápida: no Mac, um toque duplo na tecla Option abre o Claude por cima de qualquer janela. A captura de tela pela entrada rápida também é só do Mac.

Quando usar cada um

Dica

Use o navegador para conversar, escrever e analisar documentos em qualquer computador, sem instalar nada. Use o Desktop quando precisar dos recursos que só existem no aplicativo, como a aba Code, o Cowork e as extensões locais.

4. Instale o Claude Desktop no Windows

  1. Acesse o site oficial https://claude.com/download.
  2. Escolha Windows e o instalador do seu processador: x64 (Intel ou AMD) ou ARM64. Para descobrir qual é o seu, abra Configurações > Sistema > Sobre e veja o Tipo de sistema. O aplicativo também aparece na Microsoft Store.
  3. Execute o instalador baixado.
  4. Abra o Claude pelo menu Iniciar.
  5. Entre com a sua conta Claude.

5. Instale o Claude Desktop no Mac

  1. Acesse o site oficial https://claude.com/download.
  2. Baixe o arquivo DMG universal, que serve para todos os Macs.
  3. Abra o DMG e arraste o Claude para a pasta Aplicativos.
  4. Abra o Claude e entre com a sua conta.

Requisitos

  • Windows: Windows 10 ou posterior. A documentação para empresas pede o build 19041 ou superior, em x64 ou Arm64.
  • Mac: recomenda-se o macOS 14 ou posterior.
  • Conta: uma conta Claude. O plano Free já permite usar o aplicativo.

Cuidados comuns

Atenção

Baixe o aplicativo apenas em https://claude.com/download ou na Microsoft Store. Evite sites de terceiros.

Não é preciso ter conta paga para instalar: o plano Free inclui o Claude Desktop.

Nem todo recurso está em todo plano. Aba Code, Cowork e uso do computador dependem da assinatura.

Recursos documentados só para Mac, como a entrada rápida, não aparecem no Windows.

Resultado esperado

O Claude Desktop instalado no seu computador, aberto e conectado à sua conta Claude. Você sabe quando usar o navegador e quando usar o aplicativo.

Checklist da aula

  • Entendi o que é o Claude e onde posso usá-lo (navegador, computador e celular).
  • Sei a diferença entre o Claude no navegador e o Claude Desktop.
  • Baixei o instalador apenas em claude.com/download ou na Microsoft Store.
  • Instalei o Claude Desktop e entrei com a minha conta.
  • Conferi em claude.com/pricing quais recursos o meu plano inclui.

Próxima aula: você vai instalar o Claude Code no terminal do Windows (PowerShell), junto com o Node.js e o Remotion, a ferramenta que o curso usa para editar os vídeos.
