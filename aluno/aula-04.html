Aula 04: Criando sua primeira Skill personalizada

Fundamentos, instalações e Skills

Duração
≈ 7–10 min
Entrega do módulo
Aplicativo desktop, ambiente e skill personalizada
Nível
Iniciante

Objetivos da aula

  1. Ao final desta aula, você vai entender por que repetir as mesmas instruções em todo pedido é cansativo e como uma Skill resolve isso.
  2. Ao final desta aula, você vai saber diferenciar um prompt (pedido de uma tarefa específica) de uma Skill (orientações reutilizáveis).
  3. Ao final desta aula, você vai ter criado, com a ajuda do Claude Code, a Skill direcao-de-edicao em .claude/skills/direcao-de-edicao/SKILL.md.
  4. Ao final desta aula, você vai ter usado a Skill para criar uma versão vertical de 1080x1920, com 30 FPS, preservando as versões anteriores.
  5. Ao final desta aula, você vai saber atualizar a Skill com uma nova regra e aplicá-la à composição atual, sem modificar outros elementos.

Nesta aula, você cria a sua própria Skill, direcao-de-edicao, com regras visuais para todos os vídeos do curso, e a usa para gerar uma nova versão vertical da sua animação, de 1080x1920 com 30 FPS. As versões anteriores continuam no projeto.

Antes de começar

  • O projeto meu-primeiro-video com a composição de 5 segundos em 1920x1080 da aula 2.
  • A versão horizontal melhorada da aula 3, ao lado da original.
  • As Skills oficiais do Remotion instaladas na aula 3 (por isso a pasta .claude/skills já existe no projeto).

1. Prompt x Skill

Imagine precisar escrever estas instruções toda vez que pedir um novo vídeo: formato vertical, textos centralizados, margens seguras, animações suaves e fontes legíveis. Isso seria repetitivo. Uma Skill personalizada permite guardar essas orientações em um arquivo que poderá ser reutilizado.

Prompt x Skill
ConceitoO que é
PromptÉ o pedido de uma tarefa específica.
SkillÉ um conjunto reutilizável de orientações para executar determinadas tarefas.

Na aula 3, você instalou Skills prontas, escritas pela equipe do Remotion. Agora você escreve as próprias regras, com a ajuda do Claude.

2. Entenda a estrutura da Skill

Skills de um projeto ficam dentro da pasta .claude/skills, cada uma em sua própria pasta:

SKILL.md é o arquivo que contém o nome, a descrição e as regras da Skill. Ele começa com um pequeno cabeçalho de metadados entre duas linhas com três hifens (---). A descrição é recomendada, porque ajuda o Claude a reconhecer quando a Skill é relevante. Se o nome não for informado, vale o nome da pasta. Use letras minúsculas, sem acentos, com hifens no lugar dos espaços: direcao-de-edicao.

Esse exemplo serve só para você reconhecer o formato. Você não precisa escrever o arquivo à mão: o Claude cria para você no próximo passo.

  • O arquivo foi salvo em .claude/skills/direcao-de-edicao/SKILL.md.
  • Ele começa com os metadados (name e description).
  • A descrição explica quando usar a Skill.
  • As nove regras pedidas aparecem no texto.

4. Aplique a Skill

Digite /skills para verificar se a Skill está disponível:

  • Normalmente, a Skill aparece na hora, sem reiniciar: a pasta .claude/skills já existe desde a instalação da aula 3, e o Claude Code percebe as Skills novas na sessão atual.
  • Se ela não aparecer, digite /reload-skills ou feche e abra o Claude Code de novo.
  • Para chamar a Skill de forma explícita, digite /direcao-de-edicao no início da mensagem.

Em seguida, cole este prompt para fazer o teste:

Abra o Remotion Studio e selecione a nova composição na lista lateral:

Confira: a nova composição é vertical (1080x1920), roda a 30 FPS e continua com cinco segundos (150 quadros). A composição da aula 2 e a versão melhorada da aula 3 continuam na lista, em 1920x1080, para comparação.

5. Atualize a Skill

Uma Skill também pode ser atualizada; não é preciso criar outra. Observe se algum texto está muito perto da borda da tela e cole este prompt:

Abra o SKILL.md e confirme que a nova regra entrou no arquivo. No Remotion Studio, verifique se todos os textos estão dentro da margem de segurança, sem palavras cortadas, e se o resto da composição ficou igual.

Resultado esperado

Você tem a sua própria Skill e entende que ela pode ser modificada conforme suas necessidades. Não é necessário decorar códigos para criar esse tipo de instrução.

Dica

A Skill orienta o Claude, mas não garante um resultado perfeito. A avaliação final da composição continua sendo sua.

Checklist da aula

  • Criei a Skill pelo Claude Code e conferi o arquivo .claude/skills/direcao-de-edicao/SKILL.md, com descrição e todas as regras
  • Conferi com /skills que direcao-de-edicao está disponível (ou usei /reload-skills ou reiniciei o Claude Code)
  • Criei a versão vertical de 1080x1920, com 30 FPS e cinco segundos, e as versões das aulas 2 e 3 continuam no projeto
  • Atualizei a Skill com a regra da margem de segurança e corrigi só o texto perto da borda
