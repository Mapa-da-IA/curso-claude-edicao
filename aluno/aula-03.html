Fundamentos, instalações e Skills

Duração

Objetivos da aula

  1. Ao final desta aula, você vai entender o que é uma Skill e qual o papel dela ao lado do Claude Code e do Remotion.
  2. Ao final desta aula, você vai saber verificar a origem de um repositório antes de instalar algo, a partir da página oficial de Skills do Remotion.

  5. Ao final desta aula, você vai ter uma versão melhorada da composição de cinco segundos, ao lado da original, para comparar.

Nesta aula, você instala as Skills oficiais do Remotion no projeto meu-primeiro-video e pede ao Claude Code uma versão melhorada da sua animação de cinco segundos, sem apagar a original.

Antes de começar

  • O projeto meu-primeiro-video criado na aula 2, na pasta %USERPROFILE%\CursoClaude\meu-primeiro-video.
  • A composição de 5 segundos em 1920x1080 com o texto "Meu primeiro vídeo com Claude".
  • O Claude Code funcionando no seu computador.

1. O que é uma Skill

Imagine que o Claude é um editor de vídeos que sabe trabalhar com várias ferramentas. Uma Skill funciona como um manual de técnicas especializado, que ele pode consultar para executar determinados trabalhos seguindo instruções mais específicas. O Claude consegue criar animações mesmo sem Skills adicionais, mas nem sempre conhece os procedimentos mais recomendados para cada ferramenta.

Quem faz o quê
PeçaPapel
Claude CodeExecuta as tarefas.
RemotionPermite construir as animações.
SkillFornece orientações para realizar essas tarefas.

Uma Skill não é um programa de edição nem substitui o Remotion. Normalmente, é um conjunto de instruções armazenadas em arquivos como SKILL.md. O Claude pode consultar essas instruções quando forem relevantes.

2. Instale as Skills oficiais do Remotion

Passo 1 — Conheça a documentação: acesse a página de Skills oficiais do Remotion em https://www.remotion.dev/docs/ai/skills. O próprio Remotion disponibiliza instruções para ferramentas de inteligência artificial.

Atenção

VERIFIQUE A ORIGEM: antes de instalar algo de um repositório, confira quem publica. Neste caso, o comando aparece na documentação oficial do Remotion e aponta para o repositório remotion-dev/skills. Desconfie de cópias com nomes parecidos.

Passo 2 — Abra o Prompt de Comando na pasta do projeto criado na aula anterior:

Execute o comando oficial:

Se aparecerem opções de instalação, selecione o Claude Code e o projeto atual. Confirme a instalação.

3. Confira se as Skills estão disponíveis

Inicie o Claude Code na pasta do projeto:

Dentro do Claude Code, digite /skills para listar as Skills disponíveis:

  • Claude Code já estava aberto: Skills adicionadas à pasta .claude/skills do projeto passam a valer na sessão atual, sem reiniciar.
  • Exceção: se a pasta .claude/skills não existia quando a sessão começou, digite /reload-skills ou feche e abra o Claude Code de novo.
  • Uso explícito: uma Skill também pode ser chamada pelo nome, digitando /nome-da-skill.
  • Não apareceu: confira o destino selecionado durante a instalação (o projeto atual, e não outra pasta).

4. Melhore a composição de cinco segundos

Cole este prompt no Claude Code. A composição continua horizontal, em 1920x1080; o formato vertical fica para a próxima etapa do curso.

Abra o Remotion Studio e compare a composição original com a nova versão:

Anote pelo menos duas diferenças entre a composição original e a nova versão (por exemplo, tipografia, alinhamento ou suavidade da entrada).

Resultado esperado

Você entende o propósito de uma Skill, instalou as instruções oficiais do Remotion e viu uma aplicação real dessas instruções no seu projeto: a composição original e a versão melhorada lado a lado no Remotion Studio.

Dica

Skills orientam o trabalho do Claude, mas não garantem um resultado perfeito. A avaliação final da animação continua sendo sua.

Checklist da aula

  • Executei npx skills add remotion-dev/skills na pasta meu-primeiro-video, selecionando o Claude Code e o projeto atual
  • Conferi com /skills que as Skills estão disponíveis (ou usei /reload-skills ou reiniciei o Claude Code)
  • Enviei o prompt de melhoria e a composição original continua no projeto
  • Comparei as duas versões no Remotion Studio e anotei pelo menos duas diferenças
