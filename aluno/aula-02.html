Nesta aula, você vai preparar o computador (Windows 10/11) com três ferramentas: Claude Code, Node.js e Remotion. Ao final, terá um projeto Remotion aberto no Remotion Studio e o Claude Code criando a primeira composição dentro dele. Não é preciso saber programação: basta copiar os comandos na ordem.

Antes de começar

  • Um computador com Windows 10 ou 11.
  • Uma conta Claude com plano Pro, Max, Team ou Enterprise, ou uma conta do Claude Console (API). O plano Free não inclui o Claude Code.

1. O que é Node.js e por que precisamos dele?

O Node.js é um programa que permite executar JavaScript diretamente no computador, sem depender de um navegador. No curso, ele será usado principalmente para instalar e executar o Remotion, ferramenta que permite criar vídeos, animações, textos animados e motion graphics por meio de código.

As três ferramentas da aula
FerramentaPapelO que faz
Claude CodeO diretorInterpreta suas instruções e cria ou modifica os arquivos do projeto.
Node.jsO motorExecuta o ambiente de programação e permite usar ferramentas como npm e npx.
RemotionO estúdioTransforma código em composições audiovisuais que podem ser visualizadas e renderizadas.

Atenção

INFORMAÇÃO IMPORTANTE: a instalação nativa atual do Claude Code não exige Node.js. Você vai instalar o Node.js porque ele será necessário para executar os projetos do Remotion e diversas ferramentas adicionais que vamos usar no curso.

2. Instale o Node.js no Windows

  1. Passo 1 — Acesse o site oficial: Abra https://nodejs.org/pt-br/download e selecione a versão identificada como LTS, recomendada para maior estabilidade.
  2. Passo 2 — Execute o instalador: Baixe o instalador para Windows, abra o arquivo .msi, aceite a licença e mantenha as configurações padrão. Clique em Install e depois em Finish.
  3. Passo 3 — Abra o Prompt de Comando: Pressione Win + R, digite cmd e pressione Enter. Uma janela preta aparecerá. É nela que você vai testar a instalação.

3. Confira se o Node.js foi instalado

Digite os três comandos a seguir, um por vez, pressionando Enter depois de cada um.

  • node -v: Mostra a versão instalada do Node.js.
  • npm -v: Mostra a versão do npm, o gerenciador de pacotes instalado com o Node.js.
  • npx --version: Mostra a versão do npx, que permite executar ferramentas disponibilizadas por pacotes.

Se os três comandos retornarem números de versão, a instalação foi reconhecida pelo sistema. Os números não precisam ser iguais aos de outra pessoa.

Resumo: o Node.js fornece o ambiente de execução, o npm gerencia os pacotes e o npx permite executar ferramentas desses pacotes.

4. Instale o Claude Code

  1. Passo 1: No menu Iniciar do Windows, procure por PowerShell e abra-o.
  2. Passo 2: Cole o comando oficial de instalação (abaixo). Esse comando baixa e executa o instalador oficial. Use-o apenas com a URL oficial.
  3. Passo 3: Depois da instalação, feche o PowerShell, abra novamente e execute claude --version. Se aparecer uma versão, o Claude Code está instalado.
  4. Passo 4: Para iniciar o programa, execute claude. Na primeira execução, siga as instruções de autenticação.

7. Problemas mais comuns durante a instalação

  • Erro 1 — 'node' não é reconhecido: Feche o terminal e abra uma nova janela. Depois, rode o comando abaixo para localizar o Node.js. Se nada for encontrado, reinstale o Node.js LTS e abra um novo terminal.
  • Erro 2 — O PowerShell bloqueia o npm ou o npx: A mensagem diz que npm.ps1 ou npx.ps1 não pode ser carregado. Use o Prompt de Comando (cmd) em vez do PowerShell, ou rode npm.cmd e npx.cmd no lugar de npm e npx. Outra opção: no PowerShell, rode o comando abaixo (não precisa de administrador) e abra um novo PowerShell.
  • Erro 3 — 'claude' não é reconhecido: Feche e abra o terminal. Se continuar, confirme no PowerShell se o instalador criou o arquivo, com o primeiro comando abaixo. O instalador coloca o claude.exe em %USERPROFILE%\.local\bin e pode não adicionar essa pasta ao PATH. Se o resultado for True, adicione a pasta ao PATH do usuário com o segundo comando (trecho oficial da documentação) e abra um novo terminal.
  • Erro 4 — O Remotion não abre no navegador: Abra manualmente o endereço mostrado no terminal (por exemplo, http://localhost:3000). Se a porta estiver ocupada, o Remotion usa outra: use a que aparecer. Para escolher a porta, rode o comando abaixo dentro da pasta do projeto.
