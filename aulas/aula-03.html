Contexto narrativo

Continuidade da aula anterior: utilizar o projeto e os conhecimentos já construídos, sem recomeçar o processo.

Roteiro de cenas e condução

  1. A pergunta: Se Claude cria vídeos, por que instalar Skills?
  2. Definição útil: Skills são orientações especializadas armazenadas em arquivos, como SKILL.md; não substituem os softwares nem garantem qualidade.
  3. Onde buscar: Demonstre a documentação oficial remotion.dev/docs/ai/skills e verifique a origem dos repositórios.
  4. Instalação: Na pasta do projeto, execute o comando oficial npx skills add remotion-dev/skills; confira os arquivos e reinicie a sessão do Claude Code quando necessário.
  5. Teste: Consulte /skills, peça um título com boas práticas e abra a composição no Studio.
  6. Gancho: Agora criaremos regras próprias de edição.

Comando de demonstração

Skills e repositórios nesta aula

Skill obrigatória

Remotion Agent Skills: https://github.com/remotion-dev/skills. Comando principal: npx skills add remotion-dev/skills. Dentro do Claude Code, verificar remotion-best-practices.

Atenção

NOTA DE COMPATIBILIDADE E VERIFICAÇÃO: No Chat/Cowork, instalar uma Skill pela conta é outra operação. Evite colar comandos npm como se fossem instruções da interface web.

Checklist do professor

  • Skill instalada em local reconhecido
  • Claude Code reconhece ou acessa a Skill
  • O resultado foi conferido no Studio

AULA 03 / NARRAÇÃO

Texto contínuo para locução

Nesta aula, vamos trabalhar instalando skills. Explicar o conceito de Skills e instalar instruções oficiais do Remotion no projeto. Ao final, você terá um resultado concreto que pode ser conferido diretamente no projeto.

Primeiro, se Claude cria vídeos, por que instalar Skills?

Agora, skills são orientações especializadas armazenadas em arquivos, como SKILL.md; não substituem os softwares nem garantem qualidade.

Em seguida, vamos demonstrar a documentação oficial remotion.dev/docs/ai/skills e verifique a origem dos repositórios.

Na prática, na pasta do projeto, execute o comando oficial npx skills add remotion-dev/skills; confira os arquivos e reinicie a sessão do Claude Code quando necessário.

Depois disso, consulte /skills, peça um título com boas práticas e abra a composição no Studio.

Para conferir, agora criaremos regras próprias de edição.

Na próxima aula, continuaremos aprimorando a produção, aproveitando o que já foi construído.

Dica

USO DA LOCUÇÃO: Este é um texto-base de narração para leitura e adaptação pelo professor. Ajuste as frases à demonstração realmente gravada; não afirme que uma renderização ou análise funcionou antes de conferir.
