Aula 03: Instalando Skills no Claude Code

Fundamentos, instalações e Skills

Duração de referência
≈ 7–10 min (estimativa editorial do guia)
Entrega do módulo
Aplicativo desktop, ambiente e skill personalizada
Nível
Iniciante

Objetivos da aula

  1. Entender o que são Skills e qual o papel delas ao lado do Claude Code e do Remotion.
  2. Conhecer a página oficial de Skills do Remotion e verificar a origem antes de instalar algo de um repositório.
  3. Instalar as Skills oficiais do Remotion no projeto meu-primeiro-video com o comando oficial.
  4. Conferir no Claude Code, com /skills, se as Skills instaladas estão disponíveis.
  5. Usar as instruções do Remotion para melhorar a composição de cinco segundos, preservando a versão original para comparação.

Contexto narrativo

Tema: como ensinar novas técnicas ao Claude. Na aula anterior, o aluno preparou o computador e criou, no projeto meu-primeiro-video, uma composição de 5 segundos em 1920x1080 com o texto "Meu primeiro vídeo com Claude". Nesta aula, ele instala as Skills oficiais do Remotion nesse mesmo projeto e pede ao Claude Code uma versão melhorada da animação, sem apagar a original.

Comece a aula mostrando a animação de texto criada na aula anterior. Explique que o Claude consegue desenvolver animações mesmo sem Skills adicionais. Entretanto, nem sempre conhece os procedimentos específicos mais recomendados para cada ferramenta. É nesse momento que apresentamos as Skills.

Dica

DIDÁTICA DA AULA: explique para que serve, depois demonstre e por fim deixe o aluno reproduzir. O projeto é sempre o mesmo (meu-primeiro-video): a composição da aula 2 continua no projeto e a nova versão fica ao lado dela, para que o aluno compare o antes e o depois.

Roteiro de cenas e condução

  1. Resultado anterior: Abra o Remotion Studio e mostre a composição de cinco segundos criada na aula 2.
  2. A pergunta: Se o Claude já cria animações, por que instalar Skills?
  3. Conceito: Apresente a comparação do editor de vídeos com um manual de técnicas e a divisão Claude Code, Remotion e Skill.
  4. Documentação oficial: Abra a página de Skills do Remotion e explique a importância de verificar a origem antes de instalar.
  5. Instalação: No Prompt de Comando, na pasta do projeto, execute npx skills add remotion-dev/skills.
  6. Conferência: Abra o Claude Code e digite /skills para ver as Skills disponíveis.
  7. Primeiro teste: Envie o prompt de demonstração e peça uma nova versão da composição.
  8. Comparação: No Remotion Studio, compare a versão original com a nova e comente as diferenças.
  9. Gancho: Na próxima aula, vamos criar nossa própria Skill de direção de edição.

1. Como explicar o conceito para iniciantes

Use uma comparação simples: imagine que o Claude é um editor de vídeos que sabe trabalhar com várias ferramentas. Uma Skill funciona como um manual de técnicas especializado, que ele pode consultar para executar determinados trabalhos seguindo instruções mais específicas.

Quem faz o quê
PeçaPapel
Claude CodeExecuta as tarefas.
RemotionPermite construir as animações.
SkillFornece orientações para realizar essas tarefas.

Uma Skill não é um programa de edição nem substitui o Remotion. Normalmente, é um conjunto de instruções armazenadas em arquivos como SKILL.md. O Claude pode consultar essas instruções quando forem relevantes.

2. Demonstração prática: instalando as Skills oficiais

Passo 1 — Conhecer a documentação: acesse a página de Skills oficiais do Remotion em https://www.remotion.dev/docs/ai/skills. Mostre que o próprio Remotion disponibiliza instruções para ferramentas de inteligência artificial.

Atenção

VERIFIQUE A ORIGEM: antes de instalar algo de um repositório, confira quem publica. Neste caso, o comando aparece na documentação oficial do Remotion e aponta para o repositório remotion-dev/skills. Desconfie de cópias com nomes parecidos.

Se aparecerem opções de instalação, selecione o Claude Code e o projeto atual. Confirme a instalação.

Passo 3 — Conferir se funcionou: inicie o Claude Code na pasta do projeto e digite /skills para listar as Skills disponíveis.

  • Claude Code já estava aberto: Skills adicionadas à pasta .claude/skills do projeto passam a valer na sessão atual, sem reiniciar.
  • Exceção: se a pasta .claude/skills não existia quando a sessão começou, digite /reload-skills ou feche e abra o Claude Code de novo.
  • Uso explícito: uma Skill também pode ser chamada pelo nome, digitando /nome-da-skill.
  • Não apareceu: confira o destino selecionado durante a instalação (o projeto atual, e não outra pasta).

AULA 03 / NARRAÇÃO

Texto contínuo para locução

Na aula anterior, preparamos nosso computador e criamos nossa primeira animação utilizando o Claude Code e o Remotion.

Agora vamos conhecer um recurso muito importante para melhorar a maneira como o Claude trabalha: as Skills.

Mas afinal, o que é uma Skill?

Imagine que você contratou um editor de vídeos. Ele já conhece várias ferramentas, mas você quer que ele siga determinadas técnicas de edição, animação e organização.

Para isso, você entrega um manual com orientações específicas.

Uma Skill funciona de maneira parecida. Ela fornece instruções que o Claude pode consultar para realizar determinadas tarefas.

Por exemplo, podemos instalar uma Skill com orientações sobre como criar animações no Remotion, organizar elementos na tela e trabalhar com vídeos.

Isso não significa que o Claude vai produzir vídeos perfeitos automaticamente. Mas ele passa a ter acesso a orientações especializadas que podem ajudar a melhorar os resultados.

E o mais interessante é que não precisamos criar tudo do zero.

O próprio Remotion disponibiliza Skills oficiais para ferramentas como o Claude Code.

Vamos abrir o site do Remotion e acessar a página dedicada às Skills.

Aqui podemos encontrar as instruções disponíveis e o comando para instalá-las.

Agora, vamos abrir o Prompt de Comando na pasta do nosso projeto e executar o comando mostrado na tela.

Durante a instalação, vamos selecionar o Claude Code e instalar as Skills no projeto em que estamos trabalhando.

Quando o processo terminar, vamos abrir o Claude Code e verificar se as novas Skills estão disponíveis.

Pronto! Agora podemos pedir ao Claude que utilize essas orientações para melhorar nossas animações.

Vamos fazer um teste com o vídeo de cinco segundos que criamos anteriormente.

Vou pedir para melhorar a tipografia, o posicionamento do texto e a suavidade da animação, sem apagar a versão original.

Agora vamos abrir o Remotion Studio e comparar os dois resultados.

Perceba que continuamos utilizando o mesmo programa. A diferença é que o Claude tem acesso a orientações mais específicas sobre como trabalhar com ele.

E aqui está o ponto principal desta aula: as Skills ajudam a orientar o trabalho do Claude, mas nós continuamos responsáveis por avaliar o resultado.

Na próxima aula, vamos dar um passo além. Em vez de utilizar apenas Skills criadas por outras pessoas, vamos desenvolver nossa própria Skill de direção de edição.

Dica

USO DA LOCUÇÃO: Este é um texto-base de narração para leitura e adaptação pelo professor. Ajuste as frases à demonstração realmente gravada e confira o comando e as opções do instalador na página oficial antes de gravar, porque eles podem mudar.
