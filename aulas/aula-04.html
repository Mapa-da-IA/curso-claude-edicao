Aula 04: Criando sua primeira Skill personalizada

Fundamentos, instalações e Skills

Duração de referência
≈ 7–10 min (estimativa editorial do guia)
Entrega do módulo
Aplicativo desktop, ambiente e skill personalizada
Nível
Iniciante

Objetivos da aula

  1. Entender por que repetir as mesmas instruções em todo pedido é cansativo e como uma Skill resolve isso.
  2. Diferenciar um prompt (pedido de uma tarefa específica) de uma Skill (orientações reutilizáveis).
  3. Criar, com a ajuda do Claude Code, a Skill direcao-de-edicao em .claude/skills/direcao-de-edicao/SKILL.md, com as regras visuais do curso.
  4. Conferir a Skill com /skills e usá-la para criar uma versão vertical de 1080x1920, com 30 FPS, preservando as versões anteriores.
  5. Atualizar a Skill com uma nova regra e aplicá-la à composição atual, sem modificar outros elementos.

Contexto narrativo

Tema: ensinando o Claude a seguir seu estilo de edição. Na aula 2, o aluno criou no projeto meu-primeiro-video uma composição de 5 segundos em 1920x1080. Na aula 3, instalou as Skills oficiais do Remotion e criou uma versão horizontal melhorada, ao lado da original. Nesta aula, ele cria a própria Skill, direcao-de-edicao, com regras visuais para todos os vídeos do curso, e a usa para gerar uma NOVA versão vertical, de 1080x1920 com 30 FPS. As versões anteriores continuam no projeto.

Objetivo: criar a Skill direcao-de-edicao, contendo regras visuais para todos os vídeos desenvolvidos durante o curso.

Dica

DIDÁTICA DA AULA: explique para que serve, depois demonstre e por fim deixe o aluno reproduzir. O projeto é sempre o mesmo (meu-primeiro-video): a composição da aula 2 e a versão melhorada da aula 3 continuam no projeto, e a versão vertical desta aula fica ao lado delas, para comparação.

Roteiro de cenas e condução

  1. O problema: Mostre como seria repetir, em todo pedido, formato vertical, textos centralizados, margens seguras, animações suaves e fontes legíveis.
  2. Prompt x Skill: Explique a diferença entre o pedido de uma tarefa e um conjunto reutilizável de orientações.
  3. Estrutura: Mostre a pasta direcao-de-edicao e o arquivo SKILL.md, com nome, descrição e regras.
  4. Criação: Envie ao Claude Code o prompt que cria a Skill e mostre onde o arquivo foi salvo.
  5. Conferência: Digite /skills e confirme que direcao-de-edicao aparece na lista.
  6. Aplicação: Chame /direcao-de-edicao e peça a versão vertical de 1080x1920, com 30 FPS, preservando as anteriores.
  7. Resultado: Abra o Remotion Studio e compare a versão vertical com as versões horizontais.
  8. Melhoria: Aponte um texto muito perto da borda, atualize a Skill com a nova regra e corrija só esse ponto.
  9. Gancho: Na próxima aula, vamos criar nosso primeiro vídeo completo, com várias cenas e uma narrativa visual.

1. Explicação para o aluno

Comece apresentando um problema comum. Imagine precisar escrever estas instruções toda vez que pedir um novo vídeo: formato vertical, textos centralizados, margens seguras, animações suaves e fontes legíveis.

Isso seria repetitivo. Uma Skill personalizada permite guardar essas orientações em um arquivo que poderá ser reutilizado.

Prompt x Skill
ConceitoO que é
PromptÉ o pedido de uma tarefa específica.
SkillÉ um conjunto reutilizável de orientações para executar determinadas tarefas.

Na aula 3, o aluno instalou Skills prontas, escritas pela equipe do Remotion. Agora ele escreve as próprias regras, com a ajuda do Claude.

2. Vamos criar nossa Skill

Primeiro, explique rapidamente a estrutura do arquivo. Skills de um projeto ficam dentro da pasta .claude/skills, cada uma em sua própria pasta:

SKILL.md é o arquivo que contém o nome, a descrição e as regras da Skill. Ele começa com um pequeno cabeçalho de metadados entre duas linhas com três hifens (---). A descrição é recomendada, porque ajuda o Claude a reconhecer quando a Skill é relevante. Se o nome não for informado, vale o nome da pasta. Use letras minúsculas, sem acentos, com hifens no lugar dos espaços: direcao-de-edicao.

Esse exemplo serve só para o aluno reconhecer o formato. Para manter a aula simples, peça ao próprio Claude para criar esse arquivo. Abra o Claude Code na pasta do projeto:

Ao final, abra o SKILL.md criado e confira com a turma: o arquivo começa com os metadados (name e description), a descrição explica quando usar a Skill e todas as regras pedidas aparecem no texto. A estrutura .claude/skills/nome/SKILL.md está prevista na documentação oficial do Claude Code.

Dica

AGORA É A VEZ DO ALUNO: ele abre o Claude Code na pasta meu-primeiro-video, envia o mesmo prompt e confere se o arquivo foi salvo em .claude/skills/direcao-de-edicao/SKILL.md, com nome, descrição e as nove regras.

3. Aplicando a Skill

Agora que a Skill existe, vamos utilizá-la. Digite /skills para verificar se ela está disponível:

  • Normalmente, a Skill aparece na hora, sem reiniciar: a pasta .claude/skills já existe desde a instalação da aula 3, e o Claude Code percebe as Skills novas na sessão atual.
  • Se ela não aparecer, digite /reload-skills ou feche e abra o Claude Code de novo.
  • Para chamar a Skill de forma explícita, digite /direcao-de-edicao no início da mensagem.

Em seguida, faça o teste:

Abra o Remotion Studio e selecione a nova composição na lista lateral:

Confira com a turma: a nova composição é vertical (1080x1920), roda a 30 FPS e continua com cinco segundos (150 quadros). A composição da aula 2 e a versão melhorada da aula 3 continuam na lista, em 1920x1080, para comparação.

Dica

AGORA É A VEZ DO ALUNO: ele digita /skills, chama /direcao-de-edicao com o prompt de demonstração e confere no Remotion Studio o tamanho, os FPS e a duração da versão vertical. Depois, confirma que as duas versões horizontais anteriores continuam no projeto.

4. Mostrando como melhorar uma Skill

Faça uma demonstração intencionalmente simples: observe um texto posicionado muito perto da borda da tela. Explique que uma Skill também pode ser atualizada; não é preciso criar outra.

Abra o SKILL.md e mostre a nova regra no arquivo. No Remotion Studio, confira se o texto se afastou da borda e se o resto da composição ficou igual.

Dica

AGORA É A VEZ DO ALUNO: ele envia o prompt de atualização, confirma que a nova regra entrou no SKILL.md e verifica no Remotion Studio se todos os textos estão dentro da margem e sem palavras cortadas.

Resultado esperado: o aluno terá sua própria Skill e entenderá que ela pode ser modificada conforme suas necessidades. Não é necessário decorar códigos para criar esse tipo de instrução.

Dica

A Skill orienta o Claude, mas não garante um resultado perfeito. A avaliação final da composição continua sendo nossa.

Checklist do professor

  • Apresentou o problema de repetir as mesmas instruções em todo pedido
  • Explicou a diferença entre prompt e Skill com a tabela
  • Mostrou a estrutura .claude/skills/direcao-de-edicao/SKILL.md e os metadados no início do arquivo
  • Criou a Skill pelo Claude Code e conferiu o arquivo salvo, com descrição e todas as regras
  • Conferiu com /skills que direcao-de-edicao está disponível (ou usou /reload-skills ou reiniciou quando necessário)
  • Criou a versão vertical de 1080x1920, com 30 FPS, preservando as versões das aulas 2 e 3
  • Atualizou a Skill com a regra da margem de segurança e corrigiu só o texto perto da borda

AULA 04 / NARRAÇÃO

Texto contínuo para locução

Na última aula, aprendemos a instalar Skills que ajudam o Claude a trabalhar melhor com o Remotion.

Mas existe algo ainda mais interessante: nós também podemos criar nossas próprias Skills.

E é isso que vamos aprender agora.

Imagine que você está criando vários vídeos e precisa repetir as mesmas orientações: use o formato vertical, deixe os textos centralizados, mantenha uma margem de segurança e utilize animações suaves.

Fazer esse pedido uma vez é simples. Mas repetir tudo em cada projeto pode ser cansativo.

E se pudéssemos guardar essas orientações para reutilizar sempre que precisássemos?

É exatamente para isso que vamos criar nossa primeira Skill personalizada.

Ela terá o nome de direção de edição e será responsável por estabelecer algumas regras visuais para nossos vídeos.

Vamos definir, por exemplo, que os vídeos devem ter resolução de mil e oitenta por mil novecentos e vinte pixels, com trinta quadros por segundo.

Também vamos orientar o Claude a utilizar textos legíveis, respeitar as margens da tela e evitar animações exageradas.

E uma regra muito importante: preservar os arquivos originais, para não perdermos trabalhos anteriores.

Mas como vamos criar essa Skill?

É mais simples do que parece.

Uma Skill normalmente utiliza um arquivo chamado SKILL.md. É nesse arquivo que ficam as orientações que o Claude poderá seguir.

E nós nem precisamos escrever esse arquivo manualmente.

Vamos abrir o Claude Code e pedir para ele criar nossa Skill, informando o nome e todas as regras que queremos utilizar.

Depois de concluir, vamos conferir onde o arquivo foi salvo e verificar se a Skill está disponível.

Agora vem a parte mais interessante: vamos testar.

Vou pedir para o Claude revisar nossa animação anterior, mas desta vez utilizando as regras de direção de edição.

Vamos abrir o Remotion Studio e observar o resultado.

Perceba que agora temos uma maneira organizada de reaproveitar nosso padrão visual.

Mas e se descobrirmos que falta alguma orientação importante?

Não precisamos criar outra Skill.

Podemos simplesmente pedir para o Claude atualizar o arquivo existente.

Por exemplo, vamos adicionar uma regra para impedir que os textos fiquem muito próximos das bordas.

Depois disso, vamos corrigir nossa composição utilizando essa nova orientação.

E pronto! Criamos nossa primeira Skill personalizada.

Agora sabemos como instalar orientações prontas e também como desenvolver nossas próprias regras de trabalho.

Na próxima aula, vamos utilizar tudo isso para criar nosso primeiro vídeo completo, com várias cenas e uma narrativa visual.

Dica

USO DA LOCUÇÃO: Este é um texto-base de narração para leitura e adaptação pelo professor. Ajuste as frases à demonstração realmente gravada e confira o SKILL.md e a composição criados antes de afirmar que funcionaram.
