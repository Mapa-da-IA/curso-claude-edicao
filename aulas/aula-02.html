Contexto narrativo

Nível avançado · Windows 10/11. Na aula anterior, o aluno conheceu o Claude no navegador e no aplicativo desktop. Agora ele prepara o computador com três ferramentas: Claude Code, Node.js e Remotion. Ao final, terá um projeto Remotion aberto no Remotion Studio e o Claude Code criando a primeira composição dentro dele.

Explique primeiro por que cada ferramenta está sendo instalada e só depois mostre os comandos. Isso ajuda quem nunca usou programação a entender o que está fazendo.

Dica

1. O que é Node.js e por que precisamos dele?

O Node.js é um programa que permite executar JavaScript diretamente no computador, sem depender de um navegador.

No nosso curso, ele será utilizado principalmente para instalar e executar o Remotion, ferramenta que permite criar vídeos, animações, textos animados e motion graphics por meio de código.

As três ferramentas da aula
FerramentaPapelO que faz
Claude CodeO diretorInterpreta suas instruções e cria ou modifica os arquivos do projeto.
Node.jsO motorExecuta o ambiente de programação e permite usar ferramentas como npm e npx.
RemotionO estúdioTransforma código em composições audiovisuais que podem ser visualizadas e renderizadas.

Atenção

INFORMAÇÃO IMPORTANTE: a instalação nativa atual do Claude Code não exige Node.js. Estamos instalando o Node.js porque ele será necessário para executar os projetos do Remotion e diversas ferramentas adicionais que utilizaremos no curso.

2. Instalando o Node.js no Windows

Demonstração prática: mostre cada etapa na gravação.

  1. Passo 1 — Acesse o site oficial: Abra https://nodejs.org/pt-br/download e selecione a versão identificada como LTS, recomendada para maior estabilidade.
  2. Passo 2 — Execute o instalador: Baixe o instalador para Windows, abra o arquivo .msi, aceite a licença e mantenha as configurações padrão. Clique em Install e depois em Finish.
  3. Passo 3 — Abra o Prompt de Comando: Pressione Win + R, digite cmd e pressione Enter. Uma janela preta aparecerá. É nela que vamos testar a instalação.

Dica

A versão LTS muda com o tempo. Na gravação, diga apenas "a versão LTS", sem citar um número de versão.

3. Como saber se o Node.js foi instalado corretamente?

Digite os três comandos a seguir, um por vez, pressionando Enter depois de cada um.

  • node -v: Mostra a versão instalada do Node.js.
  • npm -v: Mostra a versão do npm, o gerenciador de pacotes instalado com o Node.js.
  • npx --version: Mostra a versão do npx, que permite executar ferramentas disponibilizadas por pacotes.

Se os três comandos retornarem números de versão, a instalação foi reconhecida pelo sistema. Os números não precisam ser iguais.

Resumo: o Node.js fornece o ambiente de execução, o npm gerencia os pacotes e o npx permite executar ferramentas desses pacotes.

4. Instalando o Claude Code

Agora que o computador está preparado, vamos instalar o Claude Code.

  1. Passo 1: No menu Iniciar do Windows, procure por PowerShell e abra-o.
  2. Passo 2: Cole o comando oficial de instalação (abaixo). Esse comando baixa e executa o instalador oficial. Utilize-o apenas com a URL oficial.
  3. Passo 3: Depois da instalação, feche o PowerShell, abra novamente e execute claude --version. Se aparecer uma versão, o Claude Code está instalado.
  4. Passo 4: Para iniciar o programa, execute claude. Na primeira execução, siga as instruções de autenticação.

7. Problemas mais comuns durante a instalação

  • Erro 1 — 'node' não é reconhecido: Feche o terminal e abra uma nova janela. Depois, rode o comando abaixo para localizar o Node.js. Se nada for encontrado, reinstale o Node.js LTS e abra um novo terminal.
  • Erro 2 — O PowerShell bloqueia o npm ou o npx: A mensagem diz que npm.ps1 ou npx.ps1 não pode ser carregado. Use o Prompt de Comando (cmd) em vez do PowerShell, ou rode npm.cmd e npx.cmd no lugar de npm e npx. Outra opção: no PowerShell, rode o comando abaixo (não precisa de administrador) e abra um novo PowerShell.
  • Erro 3 — 'claude' não é reconhecido: Feche e abra o terminal. Se continuar, confirme no PowerShell se o instalador criou o arquivo, com o primeiro comando abaixo. O instalador coloca o claude.exe em %USERPROFILE%\.local\bin e pode não adicionar essa pasta ao PATH. Se o resultado for True, adicione a pasta ao PATH do usuário com o segundo comando (trecho oficial da documentação) e abra um novo terminal.
  • Erro 4 — O Remotion não abre no navegador: Abra manualmente o endereço mostrado no terminal (por exemplo, http://localhost:3000). Se a porta estiver ocupada, o Remotion usa outra: use a que aparecer. Para escolher a porta, rode o comando abaixo dentro da pasta do projeto.

AULA 02 / NARRAÇÃO

Texto contínuo para locução

Na aula anterior, conhecemos o Claude e vimos a diferença entre usá-lo no navegador e no aplicativo desktop. Mas antes de começar a produzir nossas primeiras animações, precisamos preparar o computador com algumas ferramentas.

E a primeira delas é o Node.js.

Talvez você nunca tenha ouvido falar dele, mas não se preocupe. Você não precisa saber programação para entender sua importância.

O Node.js permite executar programas feitos em JavaScript diretamente no computador. E por que isso interessa para quem trabalha com edição de vídeos?

Porque ao longo deste curso vamos utilizar o Remotion, uma ferramenta capaz de transformar código em vídeos, animações e motion graphics.

Pense da seguinte maneira: o Claude será nosso diretor, responsável por interpretar o que pedimos e criar as instruções necessárias. O Node.js será o motor que permite executar nosso projeto. E o Remotion será nosso estúdio, onde poderemos visualizar as animações e transformar nossas composições em vídeos.

Uma informação importante: o Node.js não é necessário para instalar a versão nativa atual do Claude Code. Estamos instalando essa ferramenta porque ela será fundamental para trabalhar com o Remotion e outras extensões que utilizaremos futuramente.

Para começar, vamos acessar o site oficial do Node.js. Aqui, vamos escolher a versão LTS, que é indicada para quem procura estabilidade.

Depois de baixar, basta executar o instalador e seguir as etapas, mantendo as opções recomendadas.

Quando a instalação terminar, vamos confirmar se tudo está funcionando.

Abra o Prompt de Comando do Windows. Para isso, pressione as teclas Windows e R, digite CMD e pressione Enter.

Agora vamos executar três comandos: node menos v, npm menos v e npx traço traço version.

Se aparecerem os números das versões, significa que nosso computador reconheceu as ferramentas.

Mas o que são npm e npx?

O npm permite instalar e gerenciar ferramentas de programação. Já o npx facilita a execução dessas ferramentas. É exatamente isso que vamos utilizar para preparar nosso primeiro projeto de vídeo.

Na sequência, vamos instalar o Claude Code, seguindo o procedimento oficial. Depois, criaremos uma pasta de trabalho e utilizaremos o npx para gerar um projeto Remotion.

Por fim, vamos executar o projeto com npm run dev e abrir o Remotion Studio, onde poderemos acompanhar nossas futuras animações.

Com essas ferramentas funcionando, teremos o ambiente preparado para dar os primeiros comandos de criação de vídeo ao Claude.

Na próxima aula, vamos conhecer as Skills, que permitem adicionar instruções e capacidades especializadas ao nosso processo de trabalho.

Dica
