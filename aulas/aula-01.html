Contexto narrativo

Esta é uma aula de apresentação. O aluno vai entender o que é o Claude, onde ele pode ser usado, qual a diferença entre o Claude no navegador e o Claude Desktop e como instalar o aplicativo. Não há demonstração de prompts nem de edição: a parte prática do curso começa nas próximas aulas.

Roteiro de cenas e condução

  1. Abertura: Conte o que a aula vai mostrar: o que é o Claude, onde usar, navegador x desktop e a instalação do aplicativo.
  2. O que é o Claude: Apresente o assistente de IA da Anthropic e o que ele faz no dia a dia.
  3. Onde usar: Mostre as três portas de entrada: navegador, aplicativo para computador e aplicativo para celular.
  4. Navegador x Desktop: Percorra a tabela comparativa e destaque o que só existe no aplicativo.
  5. Instalação: Mostre o caminho de download em claude.com/download e os passos no Windows e no Mac.
  6. Gancho: A partir da próxima aula, o curso trabalha com o Claude Desktop instalado.

O que é o Claude

O Claude é o assistente de inteligência artificial da Anthropic. Com ele é possível conversar, escrever, analisar documentos e, quando há ferramentas conectadas, executar tarefas nelas.

Onde usar o Claude

  • Navegador: pelo site claude.ai, sem instalar nada.
  • Computador: pelo aplicativo Claude Desktop, para Windows e macOS.
  • Celular: pelos aplicativos para dispositivos móveis.

Os planos são Free, Pro, Max, Team e Enterprise. O Free já inclui o aplicativo para computador, projetos e memória. O Max oferece mais uso que o Pro. Team e Enterprise são planos para empresas, com administração centralizada. Alguns recursos dependem do plano: o Claude Code e o Cowork estão nos planos pagos, e o uso do computador fica restrito ao Pro e ao Max.

Atenção

Recursos e planos mudam com frequência e variam de conta para conta. Antes de gravar, confira https://claude.com/pricing e a central de ajuda em https://support.claude.com. Não cite preços na aula: eles também mudam.

O que só o Desktop tem

  • Aba Code: o Claude Code dentro do aplicativo, com sessões em paralelo, terminal, editor e revisão das alterações (diff).
  • Cowork: disponível no macOS e no Windows desde 9 de abril de 2026.
  • Uso do computador: só nos planos Pro e Max, em prévia de pesquisa. Precisa ser ativado em Configurações e exige o computador ligado e o aplicativo aberto.
  • Extensões locais (MCP): instaladas em Configurações > Extensões.
  • Entrada rápida: no Mac, um toque duplo na tecla Option abre o Claude por cima de qualquer janela. A captura de tela pela entrada rápida também é só do Mac.

Quando usar cada um

Dica

Use o navegador para conversar, escrever e analisar documentos em qualquer computador, sem instalar nada. Use o Desktop quando precisar dos recursos que só existem no aplicativo, como a aba Code, o Cowork e as extensões locais.

Na próxima aula, vamos instalar o Claude Code no terminal do Windows (PowerShell), junto com o Node.js e o Remotion. É essa a ferramenta que o curso usa para editar os vídeos.

Como instalar no Windows

  1. Acesse o site oficial https://claude.com/download.
  2. Escolha Windows e o instalador do seu processador: x64 (Intel ou AMD) ou ARM64. Para descobrir qual é o seu, abra Configurações > Sistema > Sobre e veja o Tipo de sistema. O aplicativo também aparece na Microsoft Store.
  3. Execute o instalador baixado.
  4. Abra o Claude pelo menu Iniciar.
  5. Entre com a sua conta Claude.

Como instalar no Mac

  1. Acesse o site oficial https://claude.com/download.
  2. Baixe o arquivo DMG universal, que serve para todos os Macs.
  3. Abra o DMG e arraste o Claude para a pasta Aplicativos.
  4. Abra o Claude e entre com a sua conta.

Requisitos

  • Windows: Windows 10 ou posterior. A documentação para empresas pede o build 19041 ou superior, em x64 ou Arm64.
  • Mac: recomenda-se o macOS 14 ou posterior.
  • Conta: uma conta Claude. O plano Free já permite usar o aplicativo.

Cuidados comuns

Atenção

Baixe o aplicativo apenas em https://claude.com/download ou na Microsoft Store. Evite sites de terceiros.

Não é preciso ter conta paga para instalar: o plano Free inclui o Claude Desktop.

Nem todo recurso está em todo plano. Aba Code, Cowork e uso do computador dependem da assinatura.

Recursos documentados só para Mac, como a entrada rápida, não aparecem no Windows.

Checklist do professor

  • Mostrou a instalação no Windows e no Mac, com os requisitos
  • Conferiu planos e recursos em claude.com/pricing antes de gravar
  • Não fez demonstrações de prompts ou de edição nesta aula

AULA 01 / NARRAÇÃO

Texto contínuo para locução

Nesta primeira aula, vamos conhecer o Claude. Você vai ver o que ele é, onde pode ser usado, qual a diferença entre usar o Claude no navegador e no aplicativo para computador e, no fim, como instalar o Claude Desktop.

O Claude é o assistente de inteligência artificial da Anthropic. Ele conversa, escreve, analisa documentos e, quando está conectado a outras ferramentas, consegue executar tarefas nelas.

Você pode usar o Claude de três formas: pelo navegador, no site claude.ai; pelo aplicativo para Windows e Mac; e pelo aplicativo de celular.

No navegador, não é preciso instalar nada. Basta entrar na sua conta, em qualquer computador, e você já tem as conversas e os projetos.

O aplicativo para computador vai além. Ele tem a aba Code, o Cowork, as extensões locais e, nos planos Pro e Max, o uso do computador. Alguns desses recursos dependem do plano, então confira o que a sua conta oferece.

Para instalar, entre no site oficial, claude.com/download. No Windows, escolha o instalador, execute e abra o Claude pelo menu Iniciar. No Mac, baixe o DMG e arraste o Claude para a pasta Aplicativos. Depois, é só entrar com a sua conta. O plano gratuito já inclui o aplicativo.

Na próxima aula, vamos usar o Claude Desktop instalado para preparar o ambiente de trabalho do curso.

Dica

USO DA LOCUÇÃO: Este é um texto-base de narração para leitura e adaptação pelo professor. Antes de gravar, confira os nomes dos planos e dos recursos nas páginas oficiais, porque eles mudam com frequência.
