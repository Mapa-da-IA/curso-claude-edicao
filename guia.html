Sobre este guia

Identidade editorial inspirada na comunicação visual do Claude; material independente.

Este guia consolida as 12 aulas do nível iniciante de edição de vídeos com Claude Code e Remotion. Foi organizado para apoiar planejamento, gravação, condução de demonstrações e validação de aprendizagem.

Papel do professor: Demonstrar o procedimento em um ambiente previamente testado, explicar o raciocínio de cada decisão, conferir o resultado real e distinguir as verificações automatizadas das avaliações criativas humanas.

Método de cada aula:

  1. Mostrar o resultado esperado
  2. Apresentar o problema
  3. Explicar o conceito essencial
  4. Executar o prompt
  5. Validar o resultado
  6. Conectar à próxima aula

Notas de produção: Duração de referência: aulas 01 a 11, aproximadamente 7 a 10 minutos; aula 12, 10 a 12 minutos. As durações são estimativas editoriais, não tempos garantidos de execução do software.

Pré-requisito: computador Windows, acesso autorizado ao Claude Code, Node.js e projeto Remotion funcional. O modelo efetivamente disponível depende da conta e do ambiente do professor. Verifique nomes de modelos e comandos antes de gravar.

Guia de plataformas

Qual Claude utilizar?

A palavra Claude pode identificar diferentes interfaces. Uma Skill instalada em um projeto do Claude Code não aparece automaticamente na conta do Chat ou Cowork. O professor deve escolher a superfície antes de seguir uma instalação.

AmbienteComo usa SkillsServe ao curso?
Claude Code (terminal / IDE)Pasta .claude/skills no projeto ou ~/.claude/skills; comandos e arquivos locais.SIM — recomendado para Remotion local.
Claude Desktop — ChatPersonalizar > Skills; instalar do diretório ou enviar ZIP.Para tarefas de texto; não equivale ao terminal local.
Claude Desktop — Cowork (macOS e Windows)Skills e plugins da conta; arquivos locais dependem das capacidades e permissões disponíveis.Alternativa visual; testar acesso à pasta e terminal.
Claude no navegadorPersonalizar > Skills, conforme recursos da conta. O Cowork não fica no navegador: é do Claude Desktop.Consultar e planejar; não presumir acesso local.
Claude Code em DesktopSe disponível na instalação, ambiente de código distinto do Chat/Cowork.Pode servir, com projeto e ferramentas configurados.

Dica

DIFERENÇA INDISPENSÁVEL: Claude Opus é o modelo. Claude Code é o ambiente de trabalho com arquivos e comandos. Claude Desktop é o aplicativo; nele podem existir Chat, Cowork e recursos de código. O navegador não executa automaticamente comandos PowerShell no PC do aluno.

Instalação A — Claude Code no projeto

  1. Abra o terminal NA RAIZ do projeto Remotion.
  2. Execute npx skills add remotion-dev/skills.
  3. Revise origem, arquivos e permissões.
  4. Inicie ou reinicie Claude Code.
  5. Peça para identificar /remotion-best-practices e faça um teste com prévia real.

Para criar uma Skill própria no Claude Code, use .claude/skills/direcao-de-edicao/SKILL.md com metadados name e description. A pasta deve estar no projeto que será editado.

Instalação B — Claude na web ou aplicativo (Chat/Cowork)

Entre em Personalizar > Skills. Para Skills do diretório, escolha Procurar Skills e Instalar. Para uma Skill personalizada, compacte sua pasta no formato ZIP e use Criar Skill > Enviar uma Skill. Os rótulos podem variar com idioma e versão.

Atenção

ATENÇÃO: enviar uma Skill para a conta não instala Node.js, Remotion ou scripts locais. No Cowork, confirme acesso efetivo aos arquivos do computador; determinadas ações exigem Claude Desktop aberto e permissões explícitas.

Verificação antes da gravação

Faça o teste na MESMA interface que os alunos utilizarão. Verifique a Skill reconhecida, as mídias existentes, a criação de um arquivo e a renderização de cinco segundos. Nunca anuncie uma instalação como universal entre produtos.

Apêndice — Instalação segura

Procedimento para professores

  1. Confirme a superfície: Claude Code (terminal/projeto) ou Claude Chat/Cowork (conta)? Um procedimento não equivale automaticamente ao outro.
  2. Verifique a proveniência: Abra README, SKILL.md, commits, issues, licenças, scripts e dependências. Não use ranking de estrelas como prova de segurança.
  3. Entenda as permissões: Skills são instruções, mas seus scripts podem acionar ferramentas; revise comandos de shell, escrita de arquivos, downloads e comunicação com APIs.
  4. Teste isoladamente: Use uma cópia de projeto e mídias não sensíveis; registre o comando, a versão e o resultado obtido.
  5. Faça uma demonstração verificável: Mostre a Skill reconhecida e o resultado após renderização. Não prometa que a experiência será idêntica no Chat web, Cowork e Claude Code.
  6. Ensine reversão: Mantenha backup e identifique os arquivos criados ou alterados; evite permissões irrestritas.

Instalação rápida de referência

Claude Code (dentro do projeto): comando acima. Claude Chat/Cowork: Personalizar > Skills > Procurar Skills > Instalar; ou Criar Skill > Enviar ZIP. Um ZIP de Skill própria é diferente de clonar um repositório GitHub.

Apêndice 01 — Fluxo técnico de referência

Projeto Remotion

Uma composition reúne resolução, taxa de quadros e duração. O curso usa 1080 × 1920, 30 FPS e 900 quadros para 30 segundos.

Arquivos estáticos

Mantenha mídias em public/videos, public/imagens e public/audios. Use referências locais compatíveis com a versão instalada. Não invente arquivos para preencher lacunas.

Renderização

Composição: O-Futuro-da-Criacao. Comando de referência:

Confirme a existência do arquivo e inspecione resolução, duração, FPS, imagem e áudio; o sucesso de uma instrução ao Claude não comprova, sozinho, a exportação.

Cuidados pedagógicos

Use mídias licenciadas; proteja arquivos originais; não conceda permissões irrestritas ao computador; avalie fontes de Skills externas; diferencie diagnóstico automático de inspeção real de vídeo e áudio.

Apêndice 02 — Glossário essencial

  • Claude Code: Ferramenta de trabalho com instruções e arquivos de projeto.
  • Remotion: Framework usado para construir composições audiovisuais programáticas.
  • Skill / SKILL.md: Documento de instruções especializadas reutilizáveis.
  • Composition: Unidade de vídeo com dimensões, FPS e duração.
  • FPS: Quadros por segundo: 30 FPS equivalem a 900 quadros em 30 segundos.
  • Fade: Transição gradual de opacidade ou volume.
  • Trim: Seleção de um trecho de vídeo ou áudio.
  • Render: Processo que gera um arquivo final reproduzível a partir da composição.
  • H.264 / AAC: Codecs de vídeo e áudio utilizados na exportação de referência.
